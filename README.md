# 32-bit-CORDIC-Processor-for-Cosine-and-Logarithmic-Computation
Designed and implemented a 32-bit CORDIC processor in Verilog for cosine and natural logarithm computation using iterative shift-add operations. Verified functionality through simulation, synthesized using Cadence Genus, and completed physical design in Innovus while analyzing timing, area, power, and post-layout performance.
